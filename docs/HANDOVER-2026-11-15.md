## 六、已知的结构性问题（明早别忘了）

1. **测试程序集编译不过 = 玩家包出不来。** `EdgeChronicles.Tests.Shared` 带 `defineConstraints: ["UNITY_INCLUDE_TESTS"]`，但在编辑器里该宏是定义的，**测试代码参与编译**。今天的首包就是这样被挡住的。→ 需要工程侧定口径：**出包时是否允许跳过测试程序集**，还是接受「测试代码必须永远能编译」这条纪律。
2. **`Always Included Shaders` 漏收录 = 画面无描边且不报错。** 现有任何门控都抓不到（CI 绿、测试绿、编译零错）。→ 美术侧要在 Gate 里加机器检查。
3. **`.meta` 的 GUID 漂移风险**：今日我清理空目录树时用宽泛的 `find -delete` 误删过 4 个文件夹 `.meta`，Unity 重新生成了新 GUID。**已从 git 还原**。今后批量删文件务必用**精确路径**。
4. **`Tools/ci/unity.sh` 找不到 Unity 时退出码 2** —— CI 上若没配 `UNITY_PATH` 会直接红，不是工程问题。
