## 0. 总则

### 0.1 本卡的定位

本卡把散在 IMPL-v3.0 / AD-03 里的美术规格整理成**可直接派工**的一组条目。每条只写四样东西：

| 字段 | 含义 |
|---|---|
| **产出路径** | 文件在工程里的落位（目录 + 文件名） |
| **命名** | 文件名 / 资产 ID 的确切写法 |
| **自动验收判据** | 机器可判的断言（由 `gate.py` 或工程侧断言脚本执行） |
| **人工验收判据** | 需要人眼/盲测判的断言 |

### 0.2 五条贯穿全卡的硬约束

1. **5 材质槽**：全项目只有 `M_Rock` / `M_Wood` / `M_Ground` / `M_Cloth` / `M_Emissive`。任何模型**材质槽数 = 1**。副本差异靠**顶点色 ±10% + 光照预设 + 雾效**。
2. **6 色语义表**：朱砂 `#C0392B` / 竹青 `#7C9A5B` / 石青 `#3E6B78` / 赭石 `#8C5A3B` / 墨黑 `#1E1B18` / 宣纸米白 `#E8DFC9`。**不新增色相**。
3. **描边形态即语义**：霸体＝单边实描，无敌＝双边中空。**不靠颜色区分状态**。
4. **墨线色是推导式**：按与背景亮度差 ≥60% 推导，**不写死色值**。
5. **玩家特效不落地**：地面形状通道只属敌人预警。锋域＝**竖直光柱阵列**，**零地面图形**。

### 0.3 三类贴图三种格式（不许混用）

| 贴图类别 | 通道 | alpha | 判读 |
|---|---|---|---|
| **模型贴图**（角色 / 场景 / Boss） | RGB 三通道：R=AO / G=Roughness / B=Emissive | **无 alpha**（不得有 tRNS） | 单张贴图承载全部材质信息 |
| **UI 图标母版与切片** | RGBA（1 主色 + 1 强调色，色块 ≤8） | **必须有 alpha**，四周透明 ≥28% | 图标本体透明，底色由面板提供 |
| **VFX 图集切片** | RGBA | **必须有 alpha**（alpha 混合） | 刀光、粒子、锋域光柱 |

> 模型贴图无 alpha、UI/VFX 必须有 alpha —— 是**不同类别的资产**，不得用同一条通道规则判。发布侧三档基线的 `uiIcons.alphaIsTransparency = true` 与 `compression = DXT5` 是 UI/VFX 这一类的口径（`Tools/build/baselines/*.json`）。

### 1.1 字段定义与共同约束

| 字段 | 含义 |
|---|---|
| ID | 资产 ID（文件名去扩展名） |

**全 16 条共有的自动验收判据**

| # | 判据 | 判定方式 |
|---|---|---|
| A-1 | `rootMotion == false` | 导入设置断言 |
| A-2 | 只含 `cv_spd` 一条曲线，且取值域 ⊆ [0,1] | 曲线通道断言 |
| A-3 | 文件名后缀 ∈ {`_F`, `_D`, `_R`}；`_F` 之外不得被预制体引用 | 引用扫描断言 |
| A-4 | `_D` / `_R` 必须位于 `_WIP/` 内 | 目录扫描断言 |
| A-5 | 循环剪辑 `loopTime == true`；非循环 `loopTime == false` | 导入设置断言 |
| A-6 | 非循环剪辑的结束帧姿势落定（末 2 帧无位移残差） | 位移曲线断言 |

**帧号口径**（全卡统一）：帧 `i` 覆盖 `[i, i+1)`，`i` 是入点；「第几帧」永远指入点；「什么时候结束」用 `i+1`。**禁止把帧号参与算术**。

### 1.6 禁止复用清单（沿用 IMPL-v2.0 §8.1）

| 禁止组合 | 理由 |

### 2.4 3 条跨组硬约束

1. **锋域不得落地**：体积壳**从角色向上展开**，范围只由光柱分布半径隐含表达；**不靠透明度叠**，两层不得共用同一壳面。
2. **反震环不得是水平圆环**：抱元破罩的反震必须**竖直朝向相机**，否则俯视角下读成地面圈。
3. **回响的第二刀光不得用增益色**：它不加锋芒层，用色会被读成"额外收益"；只能靠**窄轮廓 + 错位半拍 + 明度低一档**表达。

## 6. URP 14 适配标注汇总

> 完整差异表与处理方案见 `docs/art/outline-urp14.md` §3。本节只列**资产侧**必须改的地方。

| # | 项 | URP 17 原写法 | **URP 14 必须改成** | 资产侧影响 |
|---|---|---|---|---|
| U-1 | 渲染图 | RenderGraph（`RecordRenderGraph` / `CreateRenderGraphPass` / `UniversalResourceData` / `RenderGraphUtils`） | 经典 `ScriptableRenderPass`（`OnCameraSetup` / `Execute` / `OnCameraCleanup`） | 描边 Feature 的 C# 全部重写；**着色逻辑不变** |
| U-2 | 中间纹理 | `ScriptableRenderPass.requiresIntermediateTexture`（URP 15+） | 该属性**不存在** → 自己分配 RT 并显式 blit 拷贝 | 相机颜色副本必须手写 |
| U-3 | RT 管理 | `UniversalRenderer.CreateRenderGraphTexture` | `RenderingUtils.ReAllocateIfNeeded` | 同上 |
| U-4 | 全屏 blit | `RenderGraphUtils.BlitCameraTexture` | `Blitter.BlitCameraTexture` | 同上 |
| U-5 | Renderer Feature 阶段 | `AddRenderPasses` + `SetupRenderPasses` | 同名，但 **URP 14 的 `cameraColorTarget` 只能在 pass 内部取** | 参考实现不依赖 `SetupRenderPasses` |
| U-6 | 光照层 / Rendering Layers | 完整 Rendering Layers 纹理 | **只有 Light Layers**，无 Rendering Layer 纹理 | **不得**用 Rendering Layers 选轮廓对象 → 改用 **GameObject Layer（`EC_Outline`）** |
| U-7 | 深度法线输入 | `ScriptableRenderPassInput.Depth \| Normal` | 同名 API 存在，但编码随版本变（`UnpackNormal` vs 八面体） | **不使用深度法线纹理**；视法线由遮罩 Pass 自己输出（八面体 2 通道） |
| U-8 | 自定义 LightMode | `ShaderTagId` + `SetShaderPassName` | 同 | 5 个共享材质各加一个 `ECOutlineMask` Pass |
| U-9 | Renderer 资产类型 | `UniversalRendererData` | 命名随版本变化 | **不新建 Renderer 资产**，直接挂现有 Renderer |
| U-10 | MSAA 与自定义 RT | 自定义 RT 可自由声明 msaaSamples | 自定义 RT 的 msaaSamples **必须与相机深度附件一致** | URP Asset **MSAA = Disabled**；若将来开 MSAA，遮罩 RT 必须同采样数并补 resolve |
| U-11 | 材质槽扩展 | — | — | 5 个共享材质各补 **8 个描边属性**（`_OutlineForm` / `_OutlineWidthPx` / `_OutlineHollowGapPx` / `_OutlineColor` / `_OutlinePressColor` / `_OutlineHighlight` / `_OutlineInkDelta` / `_OutlinePixelScale`）+ 一个 `ECOutlineMask` Pass |
| U-12 | Shader 收录 | — | 同 | 三个描边 Shader 必须进 URP Asset 的 **Always Included Shaders**，否则运行时 `Shader.Find` 返回 null、描边静默消失 |
| U-13 | URP Asset / Renderer 现状 | — | — | URP Asset 与 `UniversalRenderer.asset` **已由工程侧创建**（`Assets/_Project/Settings/`）。待改 3 项：① Renderer `m_RenderingMode` 0→**2（Forward+）**；② 挂 `ECOutlineRendererFeature`；③ Always Included Shaders 收录 3 个描边 Shader。MSAA=Disabled / Intermediate=Always / DepthPriming=Off / SRP Batcher=ON **已符合** |

### 6.1 5 个共享材质的属性契约

| 属性 | 类型 | 取值 | 说明 |
|---|---|---|---|
| `_OutlineForm` | float | 0 / 1 / 2 / 3 | 0=常规墨线，1=单边实描（霸体），2=双边中空（无敌），3=反相压边 |
| `_OutlineWidthPx` | float | 基准 1080p 像素 | 按形态覆写 |
| `_OutlineHollowGapPx` | float | 基准 1080p 像素 | 双边中空的中空间隙 |
| `_OutlineColor` | color | — | 留空 = 走推导 |
| `_OutlinePressColor` | color | — | 留空 = 走推导 |
| `_OutlineHighlight` | float | 0 / 1 | 入窗亮起 1 帧 |
| `_OutlineInkDelta` | float | 0.60 | 墨线最小亮度差 |
| `_OutlinePixelScale` | float | 屏高 / 1080 | 宽度随分辨率缩放 |

> **必须是普通 float / color 属性，不得用 shader keyword**：关键字是材质级的，一旦按状态切变体就等于新增材质变体，直接违反 5 材质槽硬约束。普通属性可由 **MaterialPropertyBlock 逐 Renderer 覆写**，材质资产不变、不实例化。
