## 1. 战斗系统：10 个键

| 键 | 归属 | 说明 |
|---|---|---|
| 普攻（左键，3 段） | **门派共有** | 全门派同一套，靠门派差异只体现在"普攻段数与位移曲线参数" |
| 闪避（Space） | **门派共有** | 全门派同一套；含**完美闪避**前 6 帧 |
| 8 个门派技能 | 门派专属 | 1 核心 + 7 服务（本门派） |

**"门派共有"层的意义**：未来加第 2、第 3 个门派时，普攻与闪避**零新增资产**，只新增 8 条技能剪辑 + 1 份技传表。养成系统里，**星盘 / 特技 / 络脉 / 锋饰 / 词条 全部与门派无关**，只有 **技传（技能进阶）是门派专属**。这条分界线是"以后能开多门派"的前提，现在就画好。

### 1.1 门派与资源

**拾锋门**（占位名）。单一资源 **锋芒（5 层）**：命中按表给层、单次 ≤1；8 秒未获新层则每 2 秒掉 1。

### 1.2 8 技能表

| 技能（键） | 定位 | entryTags | 前摇 | 判定 | 后摇 | 取消 | resourceDelta | coreLink | CD |
|---|---|---|---|---|---|---|---|---|---|
| **拾锋式**（右键） | **核心·兑现** | `core` | 16 | 6（落阵） | 22 | **不可** | 消耗全部 0–5 层 | 展「锋域」半径 4m / 8s，每 0.6s 一跳，单跳 = `18 × (1 + 0.45n)` | 14s |
| 迅锋（左键） | 生成 | `light` | 8·10·14 | 3·3·4 | 10·12·18 | 可（第 2 段判定后 4 帧起） | 每段命中 +1 | 锋域内每段 +2 | 无 |
| 裂石（Q） | 生成 | `heavy` | 20 | 8 | 24 | 仅命中可（命中后 6 帧） | 命中 +2 | 锋域内 +3 | 8s |
| 回锋（E） | 位移·生成 | `dash` | 10 | 6 | 16 | 可（第 4 帧起） | 穿身 +1 | 锋域内 +2（伤害为零，以层数补偿） | 9s |
| 缚锋（F） | 控场 | `control` | 12 | 5（3m） | 18 | 仅命中可 | 命中 +1 | 锋域内对被缚目标 +2 | 12s |
| 抱元（R） | 防御 | `guard` | 8 | 12（自身霸体） | 14 | 可（霸体结束帧） | 被击 +1，单次限 2 | 锋域内被击 +2 | 15s |
| 聚锋（1） | 生成·引导 | `channel` | 10 | 引导 45（1.5s，每 15 帧结算） | 12 | 仅命中可（被击退即断） | 每次结算 +1，最多 3 | 锋域内结算间隔 ×0.5 | 20s |
| 破锋（2） | 终结 | `finisher` | 14 | 8 | 20 | **不可** | 消耗 3 层 | 锋域在场：引爆 1.8× 单跳并延长锋域 2s；无锋域：改 +2 层 | 18s |

### 1.3 取消窗口：25 组有效规则

不写 8×8 逐对表，落到 `cancel_window` 表只需 **16 组「不可」+ 9 组「仅命中可」**，其余默认放行。

| 类型 | 组数 | 具体 |
|---|---|---|
| **不可**（非自身） | **16** | 拾锋式→其余全部 7 组；破锋→除迅锋外 6 组；裂石→抱元 1 组；抱元→拾锋式 1 组；聚锋→裂石 1 组 |
| **仅命中可** | **9** | 裂石→拾锋式/回锋/缚锋/聚锋/破锋 5 组；缚锋→拾锋式/聚锋 2 组；抱元→裂石/破锋 2 组 |
| 其余 | — | 默认「可」 |

**三处硬直故意留，实现时不得当 bug 修掉**：① 拾锋式落阵 22 帧不可取消——落错位置必须付代价；② 破锋 20 帧后摇是唯一的贪刀惩罚窗；③ 重击与引导不能立刻转防御——空挥裂石必定吃一下。

## 2. 复杂联动：八层叠加

联动不是"能接在一起"，而是**每一层改变一个决策**。八层全部由数据驱动。

| # | 层 | 规则 | 改变了什么决策 |
|---|---|---|---|
| L1 | **普攻 → 层数** | 普攻命中每段 +1 锋芒 | 要不要先打普攻 |
| L2 | **层数 → 核心** | 拾锋式消耗全部层数，锋域每跳 `18 × (1 + 0.45n)` | 攒几层再放 |
| L3 | **取消窗口** | 25 组规则控制连段可行性 | 这次该接哪个键 |
| L4 | **闪避 → 强化** | **完美闪避**（前 6 帧内敌人攻击落空）触发「反锋」：下一次技能 **+1 层且不消耗**、CD 减 2s | 要不要为了触发而吃一次风险 |
| L5 | **技能 → 派生** | 不新增技能，但命中特定状态触发变体：缚锋命中被缚目标 → 下一个回锋变「破势」（无敌帧 5→8）；聚锋在锋域内满 3 层 → 结算间隔减半 | 要不要先控再打 |
| L6 | **状态联动** | 锋域在场时，7 个服务技能全部有增益（见 1.2 coreLink）；抱元被击回层在锋域内 ×2 | 战斗从哪一刻开始算 |
| L7 | **技传解锁派生** | 8 技能 × 5 阶，**某些阶位解锁新的派生效果**（拾锋式 3 阶 → 锋域结束前最后一跳翻倍；破锋 5 阶 → 引爆附带 1 次 6s 锋域） | 养成直接换战斗深度 ★ |
| L8 | **特技改"何时可用"** | 3 个被动槽，改的是规则不是数值（如「锋芒上限 +1」「拾锋式 CD −3s」「完美闪避额外回复 1 层」） | 整套连招的节奏 |

**L4 完美闪避**是这套系统里唯一"必须主动冒险"的机制——它是 8 技能 + 普攻 + 闪避三者咬合的枢纽：普攻攒层、闪避制造机会、核心兑现。

### 2.1 两条必须被玩家学会的循环

| 链路 | 步骤 | 一轮 | 教学目的 |
|---|---|---|---|
| **新手（≤4 键）** | 迅锋三段攒 3 层 → 拾锋式落阵 → 域内继续迅锋（每段 +2）→ 破锋引爆 | 9s | 先攒再放，放了还要攒 |
| **熟练（全 10 键）** | 缚锋定身 → 聚锋（域内 0.75s 满 3 层）→ 裂石 +3 → 满 5 层落阵 → 域内迅锋补层 → 破锋引爆 +2s → 抱元吃反打 → 回锋穿身 → 二次落阵 | 14s | 每个键只为让锋域更早、更久、更疼 |

## 3. 打击感规格（总表）

**规则：每条规格只在此处定义一次，其余章节只引用。**（这是 v1.0 血泪换来的第 15 条治理规则）

### 3.1 帧与时间

| 项 | 规格 |
|---|---|
| 顿帧 timeScale | **0.15**（禁 0——完全静止会被读成掉帧） |
| 顿帧时长 | 三档：轻 2 / 中 4 / 重 6 帧 |
| 受击硬直 | 三档：18 / 20 / 22 帧 |
| hold 时长 | 3.3 / 3.6 / 3.9 帧（必须在 2–4 区间内） |
| 命中停顿（hit-on-hit） | 轻 2 帧 / 中 3 帧 / 重 4 帧，**与顿帧叠加计算，不共用** |
| 完美闪避时停 | 0.2s（12 帧） |
| 前摇可读性 | 所有技能与普攻 **前摇 ≥8 帧** |
| 帧表达 | 时间量一律 `T_xxx`（elapsed）；帧 `i` 覆盖 `[i, i+1)`，只标识不参与算术 |

### 3.2 击退三档

| 档 | 招式 | 距离 | 顿帧 | 硬直 | 峰值 | 30fps 每帧 |
|---|---|---|---|---|---|---|
| 轻 | 普攻一段 | 0.3–0.6m | 2 | 18 | 5.3 m/s | 0.176m |
| 中 | 普攻二段 / 回锋 | 0.8–1.2m | 4 | 20 | 10.6 m/s | 0.352m |
| 重 | 普攻三段 / 破锋 | 1.2–1.5m | 6 | 22 | 13.2 m/s | 0.44m |

**断言**：`(收身起始进度 − 后段窗口帧数) − hitstop_time_scale × hitstop_frames ≥ 2`（全符号式）；峰值 ≤18 m/s 且 30fps 档每帧 ≤0.5m。

### 3.3 反馈三件套（每次命中都必须有）

| 通道 | 轻 | 中 | 重 |
|---|---|---|---|
| **顿帧** | 2 帧 | 3 帧 | 4 帧 |
| **镜头** | 微推 0.04s | 微推 0.06s | 微推 0.08s + 0.2° 抖动 |
| **粒子** | 沿击退矢量 12 个 | 20 个 | 30 个 + 一次地面贴花 |
| **音效** | 三层中的 2 层（刀刃 + 轻击肉声） | 三层全开 | 三层全开 + 低频冲击 |
| **手柄震动** | 0.15 强度 / 60ms | 0.3 / 90ms | 0.5 / 130ms |

**音效三层固定为**：① 刀刃划过（材质相关）② 命中肉声（力度相关）③ 金属格挡（仅霸体目标触发）。三层独立触发，不是一个整体音效包。

### 3.3.1 伪命中（孤锋崖专有 · 反直觉但必须做）

三影·无面客的假身被误击时，**不能让玩家以为输入没生效而反复空砍**。规则：

| 通道 | 假身被击时 | 理由 |
|---|---|---|
| 刀光 VFX | **照常播** | 输入有响应，玩家才不困惑 |
| 打击停顿 | **完全压掉**（0 帧） | 有停顿＝"我打中了"，会误导 |
| 血量数字 | **不跳** | 同上 |
| 手柄震动 | **不触发** | 同上 |
| 镜头反馈 | **不触发**（无微推、无抖动） | 同上 |
| 受击音 | **换成护盾吸收音**（火星 + 金属闷响），**不用命中肉声** | 听觉上给出"被挡"的信号而非"打中" |
| 额外提示 | 目标身上浮出**护盾层数 +1** 的 UI 提示 | 玩家必须知道自己打错了几层 |

**设计意图**：这套反馈把"我打空了"翻译成"我打错了"，而不是"我没打中"。若做成完全无反馈，玩家会一直重复同一个动作，直到发现打不动为止。

### 3.4 可读性

| 项 | 规格 |
|---|---|
| 刀光 | **竖直面**，高度 ≥ 角色身高 1.2×，**不落地**；命中帧被角色剪影遮挡 ≤30% |
| 地面形状 | **只属于敌人预警**；玩家自身状态与特效一律不落地 |
| 霸体 | 赤色**单边实描边 4px 常亮** + 入窗亮起 1 帧 |
| 无敌 | 纸白**双边中空描边**（内外各 2px）+ 入窗高亮 1 帧 |
| 区分方式 | 靠**形态**（常亮 vs 双边），不靠颜色；**脉冲通道在 MVP 关闭**（无敌窗口仅 5 帧 = 83ms，容不下 2Hz 的 500ms 周期） |
| 墨线 | 3px 屏幕空间，按背景亮度差推导；铁砧窟倒相为纸白 |

### 3.5 完美闪避

| 项 | 规格 |
|---|---|
| 窗口 | 闪避起手 **前 6 帧**内敌人攻击判定落空 |
| 反馈 | 时停 0.2s + 镜头推近 + 敌人动作定格 + 专属音效（与普通闪避区分） |
| 收益 | 「反锋」：下一技能 **+1 层且不消耗**，CD −2s |
| 失败 | 打空则无收益，但闪避本身的后摇照付 |

## 4. 养成系统矩阵：12 套

**设计原则（这是"种类多但不冗余"的关键）：每套养成系统必须独占一个"决策维度"，否则删掉。**

| # | 系统 | 改变哪个决策 | 与战斗的联动点 | 主要材料 | 接入表 |
|---|---|---|---|---|---|
| 1 | **修为线**（6 条 × Lv10） | **何时变强**（投入顺序） | 直接改攻击/生命/技能伤害/冷却 | 各线专属材料 | `progression` |
| 2 | **装备品阶**（3 部位 × 5 阶） | **加在哪** | 基础属性 + 词条载体 | 副本掉落 | `equipment_base` |
| 3 | **词条**（18 条随机 1–3） | **怎么变强**（随机） | 部分词条**只对特定技能生效** | 副本掉落 + 洗练 | `affix_pool` |
| 4 | **洗练「重磨」** | **怎么变强**（定向） | 定向重掷 1 条词条，含保底进度 | 洗练石 | `refine_stage` |
| 5 | **锋饰**（3 槽 × 多类型） | **加在哪**（槽位规划） | 孔位决定装哪类锋饰；可合成升级 | 副本掉落 + 合成 | `socket_item` |
| 6 | **星盘**（节点网络） | **先做什么**（顺序） | 点节点解锁被动；**同系相邻有连携**（相邻 2 个同系 → 额外效果） | 星盘点（首通/挑战） | `star_node` / `star_link` |
| 7 | **手札**（特技，3 槽） | **何时可用** | 3 个被动，**改规则不改数值**：锋芒上限 +1 / 拾锋式 CD −3s / 完美闪避额外回 1 层 | 副本掉落 | `specialty` |
| 8 | **技传**（8 技能 × 5 阶） | **战斗深度** | **阶位直接解锁派生效果**（L7）；门派专属 | 同技能材料 | `tech_skill` |
| 9 | **络脉**（角色属性网） | **与谁联动** | 不加战力，改**机制**：如"锋域内普攻不中断"、"破锋消耗可减为 2 层" | 脉络点（副本精英） | `meridian` |
| 10 | **重置**（修为 / 星盘 / 络脉） | **试错成本** | 随时免费重置，降低"点错就废" | 免费 / 少量 | `progression` 派生 |
| 11 | **解锋**（装备品阶回退） | **沉没成本** | 把成品降阶返还材料，让"重铸"可行 | 免费 | `refine_stage` |
| 12 | **名望**（通关与难度档） | **刷什么** | 解锁更高难度副本与兑换档 | 计数 | `progression` 派生 |

### 4.1 三条把养成焊进战斗的规则

| 规则 | 说明 |
|---|---|
| **词条可挂技能标签** | 18 条词条中至少 6 条带 `skill_tag`（如"拾锋式伤害 +12%"、"破锋消耗 −1 层"）。**这是"养成影响战斗"最直接的通道** |
| **技传阶位 = 派生解锁** | 技传不只是加数值，**某些阶位解锁新的派生**（L7）。玩家养的不是数字，是**招式本身变多** |
| **络脉只改机制、不加战力** | 络脉节点不给攻击力，给"锋域内普攻不中断"这类**行为修改**。它保证养成与战斗互不替代 |

### 4.2 养成面板（5 个）

修为（6 条线）· 装备（部位 + 词条 + 锋饰槽）· 星盘（节点网络）· 手札 + 技传 · 络脉。
**洗练 / 解锋**挂在装备面板内，不单开。

**三条跨组硬约束**
1. **锋域不得落地**（含引爆再展域）：体积壳**从角色向上展开**，范围只由光柱分布半径隐含表达；双层靠疏密 + 高度区分，**不靠透明度叠**，两层不得共用同一壳面材质。
2. **反震环不得是水平圆环**（抱元破罩）：必须**竖直朝向相机**，否则俯视角下读成地面圈，撞 §3.4。
3. **回响的第二刀光不得用增益色**：只能靠**窄轮廓 + 错位半拍 + 明度低一档**表达。

**格位账**：派生层 = **6 专属 + 2 通用 = 8 格** → 2048 图集 50 → **58/64，余 6 格**。上限写死为 `global_tuning.vfx_graphic_budget`（默认 **8**）；**14 格是不再开新图集的绝对上限**（50 + 14 = 64）。**派生层已用尽**——升格需走变更单，第 2 门派的 8 组派生需另开一张 2048 VFX 图集。

**Boss 护盾（孤锋崖「丛影」）**：形态＝**3 片叠瓦弧形板（非闭合圈）**，**层数＝片数**（1–3）；弧板既挂在 Boss 骨盆 / 胸口的独立挂件上，**也在血条下方以片数显示**——**玩家必须能看见自己打错了几层**，这是"打错身给 Boss 加护盾"能被察觉的前提。护盾描边为墨黑单边实描，**不占用**霸体＝赤色单边、无敌＝纸白双边两条既有通道；击碎时最外一片先崩解。抱元破罩产生的残环必须与被击碎那一片**同弧度**，玩家才看得出打掉了哪一层。护盾本体走 **Boss 1024 图集**（不占 2048 技能图集），**独立挂件不写进 rig 权重** →「2 套 rig 覆盖 3 Boss」结构不变。**护盾层数上限 3**：打错身累积到 3 片后不再增加（护盾不是越叠越厚的龟壳）。

**打错身不能被读成「我打中了」**：刀光**照常播放**（玩家确实挥了刀），但顿帧、镜头微推、手柄震动、血量数字**全部缺席**，粒子改为竖直火星（被吸收、向上飞散、不落地），音效只留金属格挡音。**护盾 +1 片是「打错了」的唯一正反馈，必须可见**——这就是护盾层数必须可见的原因。逐通道规格见 AD-03 §4.5。

**四条硬口径**
1. 5 阶一律不得同时改写 L1–L6 核心循环，避免一招把连招打散。
2. 4 阶窗口类**只动前摇与取消时点，不动后摇**——拾锋式落阵 22 帧、破锋 20 帧这两处故意硬直全表保留；前摇一律不低于 §3.1 的 8 帧下限。**前摇压缩量全部从起势停顿里扣，刀光准备动作帧数不减（≥5 帧）**；破锋霸体赤色描边的「入窗亮起 1 帧」锚定刀光出现的那一帧，前摇缩短时同步前移。
3. **锋域是玩家自身状态，按 §3.4 一律不落地**——原「半径 4m 地面圆环」画法作废，改为竖直光柱阵列的体积表达；半径 4m 仍是判定范围，且**必须让玩家一眼看出域的边界**（域内每段 +2 层是命门，边界读不准整套循环就塌）。解法见 AD-03 §4.10：12 根光柱等分排在半径 4m 圆周上 + 柱顶接**悬浮的水平细环**（离地 1.6m / 2.4m，**不是地面圈**，不违反 §3.4）。双层锋域靠**疏密 + 高度**区分，不靠透明度叠，两层不共用同一壳面。
4. **规则符不得在战斗内常驻**——40 阶全解锁后角色身上会挂最多 40 道符，§3.4 的剪影可读性与「刀光被角色剪影遮挡 ≤30%」会同时垮掉。口径：**战斗内只在规则生效瞬间浮现约 0.3s 后消散；面板内常驻**；规则的持续提示改由 HUD 承担（战斗 UI 列出当前生效的规则条目），而不是挂在角色身上。

| 破罩与护盾对位 | 残环与被击碎那片**同弧度** | 调残环弧度参数 |
### 4.6 修为线与养成的分工边界

| 问题 / 归属 | 修为线（6 条） | 养成（12 套） |
|---|---|---|
| 我该先升哪条 | ✓ 投入顺序 | |
| 我该先打哪个本 | | ✓ 掉落与卡点 |
| 属性加在哪 | | ✓ 部位 / 槽 / 节点 |
| 变强的形状 | | ✓ 词条随机 / 定向重磨 |
| 何时可用 / 在哪生效 | | ✓ 手札 / 络脉 / 技传 / 星盘 |
| 战斗节奏 | | ✓ 名望难度档 |
| 基础属性 | ✓ **独占** | ✗ 不得再出现 |
| 淬骨 | 生命上限、受击减伤 | |
| 气海 | 技能伤害倍率、内力回复、锋域内每段 +2 层 | |
| 身法 | 移速、闪避 CD、攻速 | |
| 锋锐 | 基础攻击、暴击 | |
| 心印 | 掉落率、拾取范围、材料转化 | |
| 名望 | 更高难度档解锁权 | |
| 养成独占 | | 装备品阶、词条、锋饰、星盘、手札、络脉、技传、重置、解锋 |

分工原则：**修为线只加"数值"，养成只改"结构与规则"；同一属性只在一侧出现，养成与修为线的叠加只发生在"离散效果"，不落在同一条连续数值上。**

判定口径：能写成"+X% 攻击"→修为线；改"何时可用 / 在哪生效 / 投入顺序"→养成。
撞车裁决：① 锋域内每段 +2 层只在气海线给数值，技传只解锁"第 3 段额外 +1 层"等离散阶位；② 破锋消耗层数可由词条 / 络脉 / 技传三处下降，**取最小值、不叠加**。

## 8. 资产扩展（相对 v2.0）

### 8.1 派生视觉的计数口径

**判定规则**（决定了"阶位 × 表现"要不要占新图元）——**一句话可执行版**：

> **能否用同一张贴图 + 变换/材质参数表达？能 → 0 格；不能（需要不同的轮廓像素）→ 1 格。**

| 判定 | 处理 | 占格 |
|---|---|---|
| 引入画面中此前不存在的新形状 / 新对象 | 新图元 | 1 |
| 同一形状的变体（数量 / 层数 / 节奏 / 方向 / 半径 / 时机） | 参数化复用 | 0 |
| 纯规则改写、无专属战场表现 | 通用规则符 + 面板承载 | 0 |

`tech_skill` 表新增一列 **`visual_tier` ∈ {none / param / generic / new_graphic}**，由它决定美术是否出图——**把"阶位 × 表现"变成可校验的表，而不是口头约定**。
每条 new_graphic 阶位都必须写明"为何必须新贴图"，理由不成立的直接改判 param。

### 8.4 三条实现约束（不写死，实现侧一定会画错）

**① 锋域不得落地。** 玩家自身状态与特效**一律不落地**（地面形状通道只属于敌人预警）。拾锋式的「锋域」默认画法是地面圆环——**属违规，作废**。
改为**竖直光柱阵列的体积表达**：以角色为中心的竖直光柱，范围只由**光柱阵列的分布半径**隐含表达，**零地面图形**。
双层锋域（拾锋式 5 阶）：内层 12 根 / 高 1.6m，外层 24 根 / 高 2.4m，靠**疏密 + 高度**区分，**不靠透明度叠**，两层**不得共用同一壳面材质**（否则必糊）。

**② 锋域边界必须一眼可读。** 地面圆环取消后，玩家判断"在不在域内"**全靠光柱阵列的边界读出来**——而"域内每段 +2 层"是整套战斗的命门，边界读不准整套循环就塌。
因此：**12 根光柱在 4m 半径内呈可数的环状分布**，**不排方阵、不随机散点**。玩家要能数出自己站在第几圈。

**③ 规则符不得在战斗内常驻。** 40 阶全解锁后，角色身上会挂最多 40 道符——§3.4 的剪影可读性与"刀光被剪影遮挡 ≤30%"会同时垮掉。
口径：**战斗内只在规则生效瞬间浮现约 0.3s；面板内常驻。**
规则生效的**持续提示改由 HUD 承担**（战斗 UI 列出当前生效的规则条目），而不是挂在角色身上——这样 7 个 generic 阶位在战斗里仍有明确提示，且不占剪影、不占地面。

**④ 前摇压缩的三条判据。** 拾锋式 4 阶（16→12）、破锋 4 阶（14→10）均 > 8 帧红线，成立，但：
- **压缩量全部从起势停顿扣除**，**刀光准备段帧数不减**（≥5 帧）——否则玩家看不到"要出刀了"
- **破锋霸体赤色描边的「入窗亮起 1 帧」必须锚定刀光出现的那一帧**，前摇缩短时同步前移；否则会出现「刀光已出、霸体未亮」的错位帧
- **后摇 22 / 20 帧一律不动**——那两处是故意硬直（见 §1.3）

**⑤ 迅锋 5 阶第 4 段**：复用第 3 段剪辑（动画仍 16 条），但**第 4 段的位移必须换一条递减曲线**——同一条曲线直走会"卡住"；视觉靠刀光拖尾加长 + 一道残影区分。
