# IMPL-v3.0 美术扩展规格 · 养成层（UI 图集 / 面板 / 图形语言 / 派生 VFX / 提示词）

> 继承：墨线低模·硬边水墨、5 材质槽、墨线按背景亮度差推导、纸白倒相、描边形态区分、玩家特效不落地、ΔE ≤8、顶点色 ±10%。不引入新色相。
>
> **通则修订**：锋域（拾锋式核心状态）**零地面图形**，改为竖直光柱阵列的体积表达——§3.4「地面形状只属敌人预警」同样约束玩家自身状态，原「半径 4m 地面圆环」的默认画法作废。**所有玩家侧的水平圆环（反震环、拾取范围圈）一律作废**，同类表现改竖直朝向或体积壳。

## 1. UI 图集扩容方案

两张 1024 图集（各 64 格 = 8×8 × 128px 母版 / 64px 显示）+ 一张 512 材料图集（64 格 = 8×8 × 64px 母版 / 32px 显示）。**母版尺寸按显示尺寸 ×2 定，不一律 64px**——材料只出现在列表行里（32px），母版 64px 已足。

**加载口径（MVP）**：不用 Addressables，2×1024 + 1×512 随包加载（约 4.5 MB）。**分成两张 1024 是因为单图 1024 上限，不是为了按需加载**——实现方不要按动态加载设计。

## 2. 五个养成面板的布局规格

画布 1920×1080。外壳：半透宣纸平铺 + 2px 半透墨外描边 + 1px 纸白内描边；朱砂硬边按钮，无圆角/渐变/模糊阴影；动效 ≤180ms、仅 ease-out。

**排版不得按像素硬排**：以 1920×1080 为基准画布，CanvasScaler 等比缩放（match 0.5），面板内容区一律**锚点布局**；字号支持 100/125/150% 三档；内容区预留 **20% 余量**，满级/描述文本换行不得撑破分区。

| 面板 | 尺寸 | 分区 | 核心视觉元素 |
|---|---|---|---|
| 修为 | 1920×1080 覆盖 | 左 320px 六线列表 / 右 1320px 当前线 Lv0–10 / 底 280px 消耗 | 竖向刻度条（10 级 = 10 方块，不堆图标） |
| 装备 | 1920×1080 | 上 三部位(3 阶) / 中 18 词条 / 右 锋饰 3 槽 + 洗练·解锋抽屉 | 部位卡 + 词条行(图标/槽位/值) + 3 锋饰孔 |
| 星盘 | 1920×1080 | 中央节点画布 / 右上 4 系筛选 / 底 详情条 | 节点图(12) + 同系连线（预烘焙 3 态切图）；可拖拽缩放 |
| 手札+技传 | 1920×1080 双栏 | 左 3 被动槽 / 右 8 技能 × 5 阶 | 槽位 + 每技能 5 格阶位阶梯（行首复用技能图标） |
| 络脉 | 1920×1080 | 中央网状网络 / 左 8 节点列表 / 底 机制说明条 | 网状节点 + 曲线连线（机制类带断口铰点） |

## 3. 星盘与络脉的图形语言

### 3.1 星盘：4 系用形状，不靠颜色

| 系 | 形状 | 刻纹 |
|---|---|---|
| 锋（锋域/核心） | 正圆同心环 | 环心一点 |
| 血（生命/防御） | 六边切角方 | 中心横杠 |
| 速（位移/闪避） | 三角（尖朝上） | 中心竖笔 |
| 势（资源/层数） | 菱形（尖角） | 中心三折 |

| 节点三态 | 视觉 |
|---|---|
| 未解锁 | 赭石 1px 虚描边 + 纸白实心 + 刻纹只描轮廓 |
| 已解锁（可点亮） | 墨黑 3px 实描边 + 纸白实心 + 刻纹完整描线 |
| 已点亮 | 实心填充（所属系色）+ 墨黑 3px 描边保留 + 刻纹高亮 |

| 连携 | 连线 |
|---|---|
| 潜在（仅 1 个已解锁） | 赭石 1px 虚线 |
| 已解锁未满足 | 墨黑 1px 实线，无结扣 |
| 生效（两节点均点亮） | 竹青 3px 实线 + 中点菱形结扣 |

语义由线型（虚/实/有结扣）与线宽承载，不靠颜色。**三态各烘一张贴图，运行时切图。**

### 3.2 络脉：网状，不是树

| 项 | 规格 |
|---|---|
| 拓扑 | 网状 3 层环（1 枢纽 + 3 分支 + 4 叶）——它表达"与谁联动"而非"从属谁" |
| 节点形状 | 数值类＝圆点；**机制类＝方框**；枢纽＝双环 |
| 连线 | 墨黑 1px 贝塞尔曲线；数值类贯通无断口；**机制类中点留 8px 断口 + 小方铰点** |
| "改机制"表达 | 方框 + 断口铰点 + 石青描边 + 文案冠「规则」前缀 |
| 层级 | 由内向外＝影响范围由大到小，不做明度编码 |
| **16 个 `MM_*` 机制项** | **共用同一个「机制改写」标记**（方框 + 断口 + 铰点）实例化，**0 新增图标**；不按项各配图标，也不复用星盘 4 系形状（会造成形状语义冲突） |

## 4. 派生 VFX 规格（定稿）

### 4.1 计数口径（可执行判定）

**计数单位是「新视觉对象」，不是「阶位」。判定一句话：能否用「同一张贴图 + 变换/材质参数」表达？**

| 判定 | 允许的手段 | 占格 |
|---|---|---|
| 能 | 实例数量、位置、缩放、旋转、速度、时机、透明度、材质 tint | **0 格** |
| 不能（需要不同轮廓像素） | 轮廓形状本身改变、组成元素新增/删除、笔画结构改写 | **1 格** |

按 40 阶（8 技能 × 5 阶）推演 = **6 个新视觉对象 + 2 件通用件**。

**上限两条（已写进 IMPL §8.2）**：**6 个是预算推导出的上限，14 个是不再开新图集的绝对上限**（50 + 14 = 64）。

### 4.2 6 个新视觉对象（各占 1 格 · 2048 图集 50→56）

| # | 派生 · 归属 | 效果要点 | 母题 → 变体（区分手段，非颜色） | 为何必须新贴图 | 粒子 | draw call |
|---|---|---|---|---|---|---|
| 1 | 末跳翻倍 · 拾锋式 3 阶 | 最后一跳伤害翻倍，跳数/间隔不变 | 锋域跳落点环 → 双环反向旋进 + 3 拖尾 | 双环是新形状，母版只有单环 | 24 | 4 |
| 2 | 破势 · 缚锋 2 阶 | 下一回锋变破势，无敌 5→8 帧 | 回锋刀光 → **纸白双边中空轮廓** + 角色套无敌描边形态 | 中空轮廓在 VFX 贴图里是烘焙像素，VFX 不走角色描边通道；仅延长时长玩家看不出"变体" | 18 | 4 |
| 3 | 引爆再展域 · 破锋 5 阶 | 引爆后额外展 1 次 6s 锋域 | 锋域壳 → **从破锋爆点向上抽出光柱的展开过渡** + 锋域壳复现 | 「向上抽出」与首次锋域的几何构成不同；完全复用则读不出"多了一层域" | 26 | 5 |
| 4 | 回响 · 迅锋 3 阶 | 追加错位半拍第二刀光，伤害 40%，不加锋芒层 | 迅锋竖直刀光 → 双道错位半拍（≥6 帧），第二道**窄刀光**、宽/长 60%、明度低一档 | 缩放 60% 的楔形刀光会显得更锋利，与"40% 伤害"相反，需独立窄轮廓贴图 | 20 | 3 |
| 5 | 破罩冲击 · 抱元 5 阶 | 霸体结束释放反震，碎 1 层护盾，小幅击退 | 抱元纸白双边中空壳 → **竖直朝向相机**的反震环 + 壳外带缺口残环 | 竖直环与既有任何环轮廓都不同 | 16 | 4 |
| 6 | 聚锋簇 · 聚锋 5 阶 | 引导结束时凝成三叉锋簇，悬停可拾取，被吸收 +1 层 | 聚锋向心汇聚粒 → 终点悬停三叉锋簇 | 三叉锋簇是全新对象 | 22 | 4 |

**三条跨组硬约束**
- **锋域不得落地**：体积壳**从角色向上展开**，范围只由光柱分布半径隐含表达；**不靠透明度叠**，两层不得共用同一壳面。
- **反震环不得是水平圆环**：抱元破罩的反震必须**竖直朝向相机**，否则俯视角下读成地面圈，撞 §3.4。
- **回响的第二刀光不得用增益色**：它不加锋芒层，用色会被读成"额外收益"；只能靠**窄轮廓 + 错位半拍 + 明度低一档**表达。

### 4.3 0 格（参数化复用）

| 项 | 归属 | 0 格实现方式 |
|---|---|---|
| 双层锋域 | 拾锋式 5 阶 | 同一张锋域壳**实例化 24 根 + 缩放**（内 12 根 / 高 1.6m，外 24 根 / 高 2.4m），疏密 + 高度区分，**不靠透明度叠** |
| 第 4 段 | 迅锋 5 阶 | 复用第 3 段刀光贴图 + 拖尾/残影实例化；**位移换一条递减曲线**，不与第 3 段同曲线 |

**裂石与回锋的技传阶位不产生新视觉。**

### 4.4 2 件通用件（2048 图集 2 格，56→58，余 6）

| 件 | 格 | 表现 |
|---|---|---|
| 规则符本体 | 1 | 挂在角色身上的**竖直悬浮符**（不落地、不进地面预警通道）：方框 + 断口 + 铰点，与络脉「改机制」图形同源 |
| 阶位刻度环 | 1 | 环绕符的刻度环，实例化时按阶位叠 1–5 道；未点亮＝墨黑细环，已点亮＝竹青实环 |

**规则符使用规则（不得常驻）**：**战斗内只在对应规则生效的瞬间浮现约 0.3s 后消散**；面板内常驻无妨（那是 UI，不是战场）。理由：40 道常驻符会同时毁掉 §3.4 的剪影可读性与「刀光被角色剪影遮挡 ≤30%」。
**刻度可读性**：阶位刻度环每道间隔 ≥2px、宽度 ≥1px（@64px 显示），否则 0.3s 窗口内读不出阶位；1 阶＝1 道，5 阶＝5 道。

### 4.5 Boss 护盾（丛影 · 孤锋崖附加资产 · Boss 1024 图集 3 格）

| 项 | 规格 |
|---|---|
| 形态 | **3 片叠瓦弧形板（非闭合圈）**，层数 = 片数（1–3）；闭合圈会与敌人预警圈撞语义 |
| 描边 | 墨黑单边实描；**不占用**霸体=赤色单边、无敌=纸白双边两条既有通道 |
| 击碎 | 最外一片先崩解 → 残环 + 碎片 |
| 与破罩对位 | 抱元破罩产生的残环必须与被击碎那一片**同弧度**，玩家才看得出打掉了哪一层 |
| 归属 | **独立挂件**（挂 Boss 骨盆/胸口的子物体），**不写进 rig 权重** → 2 套 rig 覆盖 3 Boss 不变 |
| 成本 | Boss 1024 图集 3 格（壳 + 崩解碎片 + 残环），**不占 2048 技能图集** |

**伪命中反馈（打错身必须可察觉、但不能读成"打中了"）**

| 通道 | 打中本体 | **打错身（假身）** |
|---|---|---|
| 刀光 | 正常播放 | **正常播放**（玩家确实挥了刀，砍空/被挡不是动作问题） |
| 顿帧 | 轻 2 帧 | **0 帧**（连轻击的 2 帧都不给） |
| 镜头微推 | 0.04–0.08s | **0** |
| 粒子 | 12–30 命中粒子 | **竖直火星**（被吸收，向上飞散，不落地） |
| 音效 | 刀刃 + 肉声 | **仅金属格挡音**（GDD 音效三层之第 ③ 层，扩用到护盾目标） |
| 手柄震动 | 0.15–0.5 | **0** |
| 血量数字 | 跳动 | **不跳** |
| 目标侧表现 | — | **护盾 +1 片**（叠瓦弧板增加一片）——这是"打错了"的唯一正反馈，必须可见 |
| 护盾描边 | — | 亮起 1 帧（与霸体亮起同语言） |

**原则**：区分靠**反馈有无与形态**（顿帧/血字/震动的缺席与火星的形态），不靠颜色。

### 4.6 聚锋簇拾取链路（0 新增 VFX 图元）

| 环节 | 实现 | 占格 |
|---|---|---|
| 凝成 | 第 6 组图元，向心汇聚到终点 | 0 |
| 悬停可拾取 | 锋簇＝世界空间子物体，自带竖直光柱（复用光柱母题）；**拾取范围不得用地面圈** | 0 |

### 4.8 前摇压缩的前摇可读性判据

### 4.10 锋域的边界可读性（域内每段 +2 层是命门）

地面圆环取消后，玩家判断"我在不在域内"只能靠光柱阵列读出来，因此：

| 项 | 规格 |
|---|---|
| 柱位 | **12 根等分排布在半径 4m 的圆周上**（可数、不排方阵、不随机散点） |
| 柱高 | 1.6m（单层）/ 2.4m（外层） |
| 顶部环 | 每根柱顶接一条**悬浮的水平细环**（y = 柱高，**离地 1.6m / 2.4m**，不是地面圈）——俯视角下这就是一条"高处的环"，边界一眼可读，且不违反 §3.4 |
| 双层 | 内环（12 柱，y=1.6m）+ 外环（24 柱，y=2.4m），**两环不同高、不同柱数**，不靠透明度叠 |
| 可读性判据 | 盲测："现在在不在域内"判断正确率 ≥90%，否则柱数/间距/环高需重调 |

### 4.11 规则符不得常驻

见 §4.4：战斗内只在规则生效瞬间浮现约 0.3s 后消散；面板内常驻无妨。

## 5. AI 生成提示词模板（UI 图标专用）

三步：**灰度线稿定形 → 单色高对比上色 → 64px 缩放核查（灰度剪影 + 盲辨）**。

```
【主体】{物件/动作}，{语义标签}，单一主体
【形态语言】墨线低模·硬边水墨；木版硬边；低多边形；硬边平涂；纯墨线轮廓 3px 等宽；单色高对比
【色彩】{1 主色 + 1 强调色}，色块 ≤8；透明背景不带底色
【构图】1024×1024；主体居中占 60–72%；四周留白 ≥20%；最多 1 层内部结构
【线与面】轮廓封闭；最小线宽 ≥6px（128 母版）；最小负空间 ≥8px；结构线 ≤12 段
【禁止】写实 / PBR / 毛发 / 渐变 / 景深 / 模糊 / 噪点 / 阴影 / 反射 / 透视 / 文字 / 数字 / 水印 / 签名 / 多主体 / 复杂背景 / 贴图 / 圆角 / 光晕 / 体积光
【64px 附加约束】灰度后轮廓仍可辨；灰阶 ≤2 级；与底板 #E8DFC9 最差对比 ≥4.5:1；同族仅靠形状可区分；不得以颜色作唯一区分
【交付】透明 PNG 1024×1024，四周透明 ≥28%；附 64px 缩略图 + 灰度剪影
```

**必含**：水墨留白 / 木版硬边 / 低多边形 / 宣纸米白 / 色块 ≤8 / 单色高对比 / 硬边平涂 / 纯墨线轮廓 / 留白 ≥20% / 透明背景
**必排**：写实 / PBR / 毛发 / 渐变 / 景深 / 模糊 / 噪点 / 阴影 / 反射 / 透视 / 文字 / 数字 / 水印 / 签名 / 多主体 / 复杂背景 / 圆角 / 光晕 / 体积光

**受控偏离**：v2.0 的「宣纸米白底」改为「底色由面板提供、图标本体透明」，否则图标带死底色、落不同底板出现色块边；其余词项继承不变。
**命名**：`UI_ICON_{系统}_{ID}` / `UI_PANEL_{系统}_9S` / `VFX_SK_{skill}_{deriv}`；母版存 `Source/`，切片存 `Atlas/`，不入 `_WIP/`。
